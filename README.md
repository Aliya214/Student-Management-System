
# Student Management System

## 1. Project Description
The Student Management System is a beginner-friendly Python application used to manage student records. It allows users to add, view, search, update, and delete student information.

## 2. Project Objectives
- Manage student records easily.
- Store student information in a JSON file.
- Calculate grades based on marks.
- Display student statistics.
- Apply Python programming concepts.
- Learn Git and GitHub repository management.

## 3. Features
- Add student records
- View all students
- Search students by ID
- Update student information
- Delete student records
- Calculate student grades
- Display average marks
- Find the highest and lowest scorers
- Save and load student records automatically
- Handle invalid inputs

## 6. Installation
1. Install Python 3 from https://www.python.org/
2. Download or clone this project.
3. Open the project folder in Visual Studio Code.
4. Open the VS Code terminal.

## 7. How to Run
Run the following command:

    python main.py

On Windows, you can also use:

    py main.py

## 8. Data Storage
The application stores student information in students.json.
This file is created automatically when a student record is saved.

## 9. Project Structure
- main.py: Main Python application
- README.md: Project documentation
- requirements.txt: Dependency information
- students.json: Saved student records
- screenshots/: Application screenshots
